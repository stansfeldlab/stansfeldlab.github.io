API and programmatic access

MemProtMD is published as plain files over HTTPS. The same addresses work from scripts, notebooks and other websites: there is no key or sign-up, and cross-site requests are allowed, so a web page elsewhere can load MemProtMD data directly. All data is licensed under Creative Commons Attribution 4.0; please cite MemProtMD when you use it.

Everything below is relative to

https://stansfeldlab.github.io/memprotmd/

Endpoints

AddressFormatContents
data/release.jsonJSONThe current release: its date, the number of entries and groups, the licence, and the address patterns on this page. Check it first to see whether anything has changed.
data/entries.tsvTab-separatedOne row per entry with the most-used fields, ready for a spreadsheet, R or pandas. The columns are listed below.
data/index.jsonJSONEvery entry and group in compact arrays, as used by this site. See Data files for the layout.
data/entries/{pdb}.jsonJSONThe full record for one entry: ref (PDB metadata), sim (simulation summary) and prof (chain profiles). {pdb} is the lower-case PDB code.
data/groups/{collection}.jsonJSONDescriptions and source links for the groups in one classification: the curated mpm, TCDB, mpstruc and Pfam, and the groupings worked out from the records, UniProt (proteins), organism, topology and ligand.
data/stats.jsonJSONThe contact tables and depth histograms behind the Statistics page.
pdb/{pdb}/HTMLA permanent web page for each entry. It carries a schema.org Dataset record (Bioschemas profile) and links to the JSON record.
sitemap.xmlXMLThe address of every entry page.

Coordinate files, images, contact tables and simulation inputs for each entry are on file storage, under the base address given on the Data files page and in files in data/release.json.

Examples

Command line

# bilayer thickness next to the protein and in bulk, for 1A0S
curl -s https://stansfeldlab.github.io/memprotmd/data/entries/1a0s.json | jq '.sim.thinning'

# the date of the current release
curl -s https://stansfeldlab.github.io/memprotmd/data/release.json | jq -r '.release'

Python

import pandas as pd

t = pd.read_csv("https://stansfeldlab.github.io/memprotmd/data/entries.tsv", sep="\t", dtype={"pdb_id": str})

# X-ray GPCR structures at 2.5 Å or better, thinnest bilayer next to the protein first
gpcr = t[t.memprotmd_groups.str.contains("gpcrs", na=False)
         & t.method.str.contains("X-RAY", na=False)
         & (t.resolution_A <= 2.5)]
print(gpcr.sort_values("annular_thickness_A")[["pdb_id", "title", "annular_thickness_A"]])

JavaScript

const rec = await fetch("https://stansfeldlab.github.io/memprotmd/data/entries/1a0s.json").then(r => r.json());
console.log(rec.ref.title, rec.sim.thinning.annular_thickness);

Columns in entries.tsv

Lists within a cell are separated by a semicolon and a space. Empty cells mean the value is not recorded.

ColumnMeaning
pdb_idLower-case PDB code.
titleTitle of the PDB entry.
methodExperimental method as given by the PDB, for example X-RAY DIFFRACTION or ELECTRON MICROSCOPY.
resolution_AResolution in ångströms. Missing for most cryo-EM and all NMR entries.
releasedPDB release date.
uniprotUniProt accessions of the protein chains.
organism, ncbi_taxid, domainSource organism of the chains placed in the membrane, from the RCSB PDB, with its NCBI taxonomy id and domain of life (Eukaryota, Bacteria, Archaea or Viruses).
n_chains, n_lipids, n_protein_residuesSize of the simulated system.
bulk_thickness_A, annular_thickness_A, thickness_change_ABilayer thickness away from the protein and next to it, and the difference, in ångströms.
memprotmd_groups, mpstruc, tcdb, pfamThe most specific groups the entry belongs to in each classification, as accessions. Group pages are at #/ref/{collection}/{accession}.
entry_url, record_url, files_urlThe entry's web page, its JSON record and its folder on file storage.

Releases

The site checks the MemProtMD database four times a day, and new or updated entries appear as soon as they are found. Releases are weekly: each Monday, if anything has changed, the data is labelled with that date and a snapshot of data/entries.tsv, data/index.json and data/release.json is kept as a GitHub release. data/release.json gives the current release and the date of the latest change (updated), and both are shown at the foot of every page. When you cite MemProtMD data, give the release you used.

Moving from the old API

The server-side API at memprotmd.bioch.ox.ac.uk/api/ (requests such as POST /api/search/advanced with collectionName refs or simulations) is being retired along with that server. Use these files instead:

Old requestReplacement
refs for one PDB entryref in data/entries/{pdb}.json
simulations for one entrysim in data/entries/{pdb}.json
Searches and listings across entriesdata/entries.tsv, or data/index.json for group membership
Files for one simulationThe folder in files_url, laid out as on the Data files page
