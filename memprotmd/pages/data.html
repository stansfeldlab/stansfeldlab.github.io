Data files and layout

Everything in MemProtMD is available as plain files over HTTPS. No account or API key is needed, and all files are licensed under Creative Commons Attribution 4.0. This page describes where each file lives and what it contains.

Base address

All paths below are relative to one base address. At present this is:

https://memprotmd.bioch.ox.ac.uk/data/memprotmd/

Each simulation has an identifier made from the lower-case PDB code and the simulation set-up, for example 1a0s_default_dppc: PDB entry 1A0S, default protocol, DPPC bilayer.

Folder layout

simulations/
  <pdb>_default_dppc/
    images/                     rendered views (JPEG)
    files/structures/           coordinate files (PDB)
    files/contacts/             per-residue analysis (CSV)
    files/run/                  ready-to-run simulation inputs (ZIP)
    *.latest.yml                analysis results (YAML)
databases/
  <collection>/thumbs/          thumbnails for PDB entries and groups
  mpm/stats.csv                 histograms for each MemProtMD group
ensembles/
  statistics/                   statistics across all simulations

Files for one simulation

Structures

FileContents
files/structures/ready.pdbThe protein structure as prepared for simulation.
files/structures/at.pdbFinal snapshot at atomistic resolution: protein, lipids, water and ions, converted from coarse-grained with CG2AT.
files/structures/cg.pdbFinal snapshot in coarse-grained (MARTINI) representation.
files/structures/web_vis.pdbA reduced atomistic snapshot for viewing in a web browser.
files/structures/distortions.pdbThe average membrane surface, written as PDB so it can be opened alongside the protein.
files/structures/group_head.contacts.pdb
group_tail.contacts.pdb
group_solvent.contacts.pdb		The protein with lipid head-group, acyl-tail or solvent contacts written into the temperature-factor column, ready for colouring in a molecular viewer.

Simulation inputs

FileContents
files/run/at.zipGROMACS input files to continue the simulation at atomistic resolution.
files/run/cg.zipGROMACS input files for the coarse-grained simulation.

Analysis

FileContents
files/contacts/by_resid_postprocess.csvOne row per residue. See the column list below.
files/contacts/relative_z_histogram.csvFor each chain, the density of each amino acid type, and of helix, strand and other residues, in slices along the bilayer normal.
thinning.latest.ymlBilayer thickness in the bulk and next to the protein, and the difference between them, in ångströms.
build_ss_topology.latest.ymlFor each chain, the helices and strands with their start and end residues and their path relative to the bilayer. This drives the topology view.
align_sim_structure.latest.ymlThe mapping between residues in the simulation and residues in the original PDB entry, with secondary structure.

Images

Rendered with VMD and Tachyon. All are in images/.

FileContents
thumb_50.jpg, thumb_100.jpg, thumb_250.jpgThumbnails of the protein in its bilayer.
front-cartoon.jpg, top-cartoon.jpg, bottom-cartoon.jpgThe protein alone, from the side, from above and from below.
front-cg_lipids.jpg, front-at_lipids.jpgThe protein with coarse-grained or atomistic lipids.
front-distortions.jpg, top-distortions.jpg, bottom-distortions.jpgThe average membrane surface, coloured red where the bilayer is thinner than bulk and blue where it is thicker.
front-contacts-{head,tail,solvent}-{cartoon,surface}.jpgThe protein coloured by contact with lipid head groups, acyl tails or solvent, as cartoon or surface.

Columns in by_resid_postprocess.csv

Contact values are the fraction of frames, from 0 to 1, in which the group is within 6 Å of the residue over the final 800 ns of the simulation.

ColumnMeaning
chainID, chainInstance, resSeq, iCode, resNameResidue identity, matching the PDB entry.
DSSP, ssSecondary structure: the DSSP code, and a summary of alpha, beta or none.
alignedWhether the residue could be matched to the original PDB entry.
tempFactorTemperature factor from the original structure.
leaflet=a;resname=DPPC;bead=Phosphate
and similar		Contact with one lipid bead type in one leaflet. Leaflets are a and b; flip is lipid that changed leaflet. Beads are Choline, Phosphate, Glycerol and Tail_1 to Tail_4.
leaflet=sol;resname=W;bead=Water
leaflet=sol;resname=ION;bead=Sodium, Chloride		Contact with water and with each ion.
group=Head, group=Tail, group=SolventContact summed over head-group beads, tail beads, or water and ions.
leaflet=a, leaflet=b, leaflet=flip, leaflet=solContact summed by leaflet.
x, y, zAverage position of the residue, in ångströms.
rel_z_annular, rel_z_20Position along the bilayer normal relative to the bilayer centre, measured against the lipids next to the protein.
leaflet_upper, leaflet_lowerPosition relative to the upper and lower leaflet.
surface, pore_inner_surfaceSolvent or lipid exposure of the residue, and whether it lines an internal pore.

Index of entries

This site reads one index file, data/index.json, which lists every entry and group. It can be fetched directly to enumerate the dataset.

KeyContents
pdbOne array per entry: PDB code, title, subtitle, experimental method, resolution in ångströms, release date.
colsFor each collection, one array per group: accession, title, number of simulations, parent group, subtitle, and the member PDB codes separated by spaces.

Example

Download the atomistic snapshot and the per-residue analysis for 1A0S:

BASE=https://memprotmd.bioch.ox.ac.uk/data/memprotmd
curl -O $BASE/simulations/1a0s_default_dppc/files/structures/at.pdb
curl -O $BASE/simulations/1a0s_default_dppc/files/contacts/by_resid_postprocess.csv
