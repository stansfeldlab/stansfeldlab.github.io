Research Tools

Available research tools.

MemProtMD

Database of Membrane Protein Structures

www.memprotmd.bioch.ox.ac.uk

MemProtMD Colab Notebooks

Google Colab notebooks for running the MemProtMD pipeline

github.com/pstansfeld/memprotmd

CG2AT

A tool for converting between Coarse-Grained and Atomistic

github.com/pstansfeld/cg2at

CG2AT-lite

A simplified tool for conversion between Martini Coarse-Grained and CHARMM36m

github.com/pstansfeld/cg2at-lite

CCD2MD

A tool for setting up MD simulations from co-folded complexes

github.com/pstansfeld/CCD2MD

MemPrO

A membrane protein orientation method

github.com/pstansfeld/MemPrO

MemPrOD

A tool for predicting bilayer deformations around membrane proteins

github.com/pstansfeld/MemPrOD

PyLipID

A Python package for lipid interactions analysis

github.com/pstansfeld/PyLipID

LipIDens

Simulation-assisted interpretation of lipid densities

github.com/pstansfeld/LipIDens
